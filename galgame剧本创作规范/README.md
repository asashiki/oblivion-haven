# Galgame 剧本创作规范

这个目录用于给 AI 生成 blog 内 Galgame / 视觉小说部分的剧本时提供统一上下文。

目标不是把所有内容写死，而是把三件最容易漂移的东西固定下来：**素材事实、Alice 的角色声线、TTS 的表演标注方式**。

## 文件说明

### `剧本资料.md`

剧本的素材库与已确认设定。

这里保存 Asashiki、Alice、blog、世界观、兴趣、梗、设计初衷等已经聊清楚的内容。写剧本时可以从这里取材，但不要为了“完整”把所有资料一次性塞进对白。

它主要回答：**Alice 知道什么，以及有哪些真实材料可以写。**

### `Alice-语言规范-v0.1.md`

Alice 的角色声线规范。

规定她对客人和ご主人様分别怎么说话、日语语域、吐槽力度、Meta 的使用方式、信息密度，以及需要避免的模板化二次元腔和 AI 腔。

它主要回答：**Alice 会怎么说。**

日语作为 Alice 的声线母版。中文和英文版本应按同一人格重新自然表达，不建议先写中文再逐句翻译成日语。

### `TTS-剧本标注规范-v0.1.md`

只负责配音生产相关的表演信息。

剧本层记录通用的 `delivery`、停顿、非语言动作和 voice take，不直接绑定 Fish Audio 或 MiniMax 的专用 prompt / API 参数。实际合成时再由对应适配层转换。

它主要回答：**这句话应该怎么演、哪些句子应该一起生成。**

## 推荐使用方式

生成一段剧本时，AI 应同时读取：

1. 当前分支 / 节点要表达的内容；
2. `剧本资料.md`；
3. `Alice-语言规范-v0.1.md`；
4. `TTS-剧本标注规范-v0.1.md`。

推荐顺序：

```text
分支目标 + 剧本资料
        ↓
生成 Alice 的日语对白
        ↓
按 Alice 语言规范检查、去掉 AI 味
        ↓
补充 TTS delivery / take / pause 等轻量标注
        ↓
人工修改
        ↓
Fish Audio / MiniMax 配音
```

如果使用「活人感写作」一类去 AI 味规则，它负责润色最终对白，不取代 Alice 的角色规范。润色时不能为了句子更“工整”而改掉角色停顿、口吻、Meta 反应和已经确定的事实。

## 写作原则

这个项目的第一章主要用于介绍 blog、站长和 Alice，本身只有轻量 Meta，不需要为了显得有故事而强行扩写世界观。

玩家是在点菜单、逛网站，不是在读论文。普通节点优先 1～3 个文本框，一两句话能讲清楚就停。更深的内容留给玩家继续点击。

AI 可以使用资料里的梗，但不要每一段都安排笑点。Alice 大多数时候温柔、友善、自然，吐槽ご主人様只是熟人关系的一部分。

资料里标为「暂定」「未定」「以后再说」的内容不能擅自补成正式设定。

## 版本维护

Alice 声线和 TTS 标注规范都采用版本号。实际生成一批剧本并试听后，再根据出现的问题更新到 v0.2、v0.3。

`剧本资料.md` 更接近持续追加的素材库，可以随项目进展直接更新。
