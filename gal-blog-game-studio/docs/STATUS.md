# 第一版功能状态

## 已实现

- 默认亮色编辑工作区，左侧只保留“故事地图 / 素材库 / 试玩修订”三条主路径；完整专业工作台保留为高级模式，两者共享同一 Story IR。
- 默认项目只登记用户提供的两张爱丽丝立绘与一张白昼茶室背景；没有文件的 BGM、语音、音效、夜景和表情差分保持为空。
- 语义素材卡：浏览器上传、立绘 Skill ZIP/manifest 导入、类型推断与人工修正、本机 IndexedDB 保存、自然语言说明、推荐用途、标签、别名、删除和角色表情组；素材名/角色名可点击复制。
- 素材助理允许无文件对话；无匹配素材时只保存整理意图，点名已有素材时执行透明的确定性整理并进入撤销历史。内置 17 个 WebGAL Terre 常用演出供 AI 调用。
- 确定性的本地导演规则（明确标注非 AI）：按剧情概括与素材说明选择背景、BGM、角色、表情、站位和转场，不给不存在的资源造引用。
- 地图节点直接创建剧情片段；本地规则草稿与修订只改当前片段，同时保留外部路线、存档点和系统动作。
- Story IR 1.0：项目、章节、场景、块、角色/表情、资源、变量、路线、结局、存档、AI 配置、Blog 动作。
- Zod 结构校验与完整跨引用诊断：重复 ID、章节/场景、角色/表情、变量、路线、结局、存档点、AI 配置及缺失资源。
- 资源/角色/表情别名解析，不静默生成坏路径。
- JSON、Markdown、Ren'Py-like、WebGAL、标签式、中文自然语言导入。
- 全类型剧情块表单编辑、局部修改、禁用、排序、复制与场景创建；舞台动作可编辑表情、站位、转场、时长、音量和 transform。
- 角色创建/编辑、表情差分追加、资源注册与别名测试；项目、WebGAL、Terre、Blog Bridge 和变量注册表均有可视化设置。
- StoryPatch、逆向操作、浏览器撤销/重做、历史抽屉与自动保存。
- 月姬式纵向叙事地图：故事自上而下推进、同层分支横向展开；拖动过程使用本地受控节点状态，避免坐标回写冲突；支持自动竖排、自由拖动、开始、公共线、角色故事、场景故事、普通/坏/真结局。
- 简单地图仅保留作者视图；节点与外层细线可增删和选择，线条允许交叉，节点增删会清理引用；地图与右侧片段面板可拖动调整宽度。
- ADV 与 NVL/日记模式，可在同一场景中切换。
- 片段内按播放顺序排列多组选项；可移动到片段开头、中间或结尾。选项可继续、跳到本段/别段任意选项组、自循环、结束片段或写入一次性记录。
- 继续型选项可只改变紧随其后的一句台词、角色、表情、站位或 transform，下一句自动汇合；一次性记录在内循环中不会重复取得。
- 外层细线只表示片段结束后的主干，支持单记录、全部记录与一组记录至少 N 个的进入条件。
- 输入到 story/blog/ai 的目标标记；发布运行时向博客和 AI provider 转发 `player-input`。
- 默认试玩会把当前项目即时编译为 WebGAL 文件，通过同源 Service Worker 虚拟文件系统交给官方 WebGAL 4.6.2 iframe 运行；任意中段片段会补齐只用于预览的 entry stage。旧 Story IR 快速播放器只作为明确标注的故障回退。
- 角色资源支持默认胸像、腰上、膝上与全身镜头；试玩修订中的每句对白可独立覆盖角色、表情、左中右、缩放与纵向位置，并把这些值编译为 WebGAL `changeFigure -transform`。
- Story IR → WebGAL 4.6.2 编译。
- WebGAL Terre 官方动画预设随包导出：淡入淡出、方向入场、震动、推近、模糊、电影滤镜与冲击波；`fade` 友好别名会安全映射为官方 `enter` / `exit`。
- BGM 淡入淡出与 WebGAL 0–100 音量编译；全舞台特效通过 `setAnimation` 实际执行。
- WebGAL 原生块逃生口。
- Web ZIP、Story JSON、嵌入清单与资源清单导出；浏览器内真实素材二进制会一并写入，读取失败时阻止伪完整导出。
- Terre 工程写入、Web 导出与编辑预览 WebSocket 适配层。
- Blog Bridge request/reply、origin/source/capability 校验、多允许来源选择、超时与完整动作集；导出游戏会真实暂停 WebGAL、等待三态结果、写回变量并继续或分支。
- AI 语义工具 API、通用 Patch API、编译 API。
- AI 工具验收样章：四个外层片段、多组局部选择、返回循环、标准腰上立绘与 Q 版全身演出；完整贯通三份真实素材、剧情地图、官方 WebGAL 试玩与编译。

## 明确保留接口、尚未完成生产实现

- AI Provider：已有本地规则、tool/patch 协议、AI 配置和运行点，但未绑定具体模型、联网推理或密钥管理服务，因此当前不能宣称自然语言能力由真实 AI 提供。
- 云端素材存储与生成：浏览器本机上传、语义说明和本地预览已实现；尚未实现对象存储、跨设备同步或图像/语音生成服务。
- Blog 表单：Bridge 与三态剧情已实现，真实留言、友链、图片上传 UI/后端应由 gal-blog 提供。
- 多用户协作与云端持久化：领域层可迁移，当前默认是单用户 localStorage + 文件导入导出。
- 逐操作版本 diff UI：已有 Patch、inverse 和快照历史；当前界面显示操作历史，尚未做字段级并排 diff。
- WebGAL 存档深链到任意 block：嵌入清单和 save point 数据已生成，最终恢复需要宿主/引擎扩展消费 blockId。
- AI 实时流式执行：已有受约束回合、工具限制和 fallback；provider 接入后再实现流式审核与逐操作动画。

这些项目没有从架构中删除，入口、数据结构或适配接口均已保留。
