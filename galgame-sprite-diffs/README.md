# Galgame Sprite Diffs Skill

这是 ChatGPT 当前使用的 `generate-galgame-sprite-diffs` Skill 的可移植归档版本。

它包含：

- 三种经过审核的运行姿势与表情母版流程；
- 眼睛/嘴巴蒙版、固定坐标 edit plate 与强制合成；
- WebGAL 口型同步、眨眼、透明度和像素级 QA；
- `deliverables/` 导出结构、离线预览和运行时合成器；
- 完整的 Skill 说明、参考文档与脚本。

入口文件：`SKILL.md`。  
不要把 `work/` 中的模型中间产物直接当成最终立绘；最终素材必须经过本 Skill 的强制合成和 QA。
