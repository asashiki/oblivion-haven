# grok-galgame-sprites

Grok Imagine 2.0 workflow for **transparent Galgame standing sprites** (reference / poses / expressions).

This skill is intentionally separate from the Codex skill `generate-galgame-sprite-diffs` in the same repo:

- **This skill:** solid `#FF00FF` chroma → cutout → transparent 1024×1536 mothers. No blink / mouth-sync runtime.
- **Codex skill:** full WebGAL differential pipeline including forced local eye/mouth composites.

See `SKILL.md` for the agent instructions.
